# Which states can share a signal?

A decoder sees a signal about a hidden state and translates each source request into a target move. For a finite state space, call a set of states feasible if each request has a single target move that works everywhere in that set. Draw a hyperedge around each inclusion-minimal infeasible set. A signal admits a decoder exactly when every edge contains two states with different signals. This is a *weak coloring* of the hypergraph. In the ferry example, each of three channels closes at exactly one tide. The only edge contains all three tides. Coloring two of them alike is safe. For the stranded ferry, the single tide forms an edge on its own, so every coloring fails. [Coloring theorem](../../Examples/Tutorials/HintColoring.lean) · [Ferry examples](ferry-crossing.md) · [Conflict tests](../../PolyFunTest/Examples/WeakVertexColoring.lean)

Any indexed family of nonempty finite forbidden sets has a board with precisely those coloring constraints. Give each set its own request. A target alternative names a vertex of that set and reproduces the request everywhere except at that vertex. A group of states can honor the request exactly when some vertex of the forbidden set lies outside the group. The board recovers the inclusion-minimal input sets as its obstruction edges. It recovers the whole family when no distinct member contains another.

Matroid circuits give another instance of the same rule. Take the matroid’s ground set as the vertices and its circuits as the edges. Every color class is independent exactly when the coloring splits every circuit. This works for infinite ground sets as well. A loop forms a singleton circuit, while an empty ground set can use zero colors even if the ambient type has elements.
